⚙️ How It Works

  1. User uploads study material
  2. Text is extracted and split into chunks
  3. Chunks are converted into vector embeddings
  4. Embeddings are stored in FAISS vector database
  5. User query retrieves relevant chunks
  6. LLM generates answer from retrieved context

🚀 Key Features

  • Syllabus-based answers
  • No AI hallucination
  • Fast exam revision
  • Docker-based deployment
  • Secure and offline capable

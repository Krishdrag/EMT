⚙️ Functional Requirements (IMPORTANT for Report)

The system shall:

Allow students to upload PDF study material

Extract and process text from uploaded PDFs

Convert text into vector embeddings

Store embeddings in a vector database

Accept user questions in natural language

Retrieve relevant study content using RAG

Generate accurate answers from retrieved content only

Display responses via a web interface

Run the complete system using Docker containers
